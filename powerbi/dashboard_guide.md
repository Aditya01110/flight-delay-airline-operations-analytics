# Power BI Dashboard Guide

## Recommended KPI Cards
- Total Flights
- On-Time %
- Average Arrival Delay
- Cancellation %

## Visuals
1. Monthly delay-rate trend
2. Delay rate by airline
3. Average departure delay by origin airport
4. Delay rate by scheduled departure hour
5. Cancellation reason breakdown
6. High-volume route risk table
7. Airline delay-recovery ranking

## Filters
- Month
- Airline
- Origin Airport
- Destination Airport

## Important
Use the same delayed-flight definition as the notebook:
arrival delay >= 15 minutes on completed, non-diverted flights.

If you create a `.pbix`, add it to this folder. Also export one dashboard screenshot as PNG so recruiters can preview it directly on GitHub.
